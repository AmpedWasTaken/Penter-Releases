# Penter-Releases

**Binary-only** public channel for Penter Windows installers and update metadata.

- No source code
- No credentials, evidence, or workspace exports
- Installers are **unsigned** — do not disable Windows protection to install
- Source remains private at `AmpedWasTaken/Penter`

Downloads are gated on [penter.dev](https://www.penter.dev) until public beta activation.
